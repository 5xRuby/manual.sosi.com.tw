## SSH 裝置設定

SSH（Secure Shell）是一種加密網路協定，用於在不安全的網路上安全地操作網路服務。設定 SSH 裝置時，除了基本參數外，還需填寫 SSH 特定的連線參數。

### 基本設定

與其他裝置類型共通的設定項目，請參考[裝置列表](/zh/admin/devices/)中的說明，包含：

- **裝置識別名稱**
- **IP / Hostname**
- **類型：** 選擇 SSH
- **同時連線數目上限**
- **伺服器埠號：** SSH 預設為 **22**
- **備註**
- **連線時間限制**
- **負責人信箱**

### SSH 特定設定

以下設定為 SSH 裝置類型專屬：

#### 允許的域名（Host Key）

填入遠端 SSH 伺服器的 Host Key（公鑰），用於驗證伺服器身分，防止中間人攻擊。

#### 伺服器存活間隔（Server Alive Interval）

設定 SSH 連線中傳送 keep-alive 封包的間隔時間（單位：秒）。在網路環境不穩定時，可避免連線因閒置過久而中斷。

#### 指令（Command）

設定 SSH 連線建立後自動執行的指令或腳本。可於此處設定連線後直接執行的操作，如自動切換目錄或進入特定程式。

#### 地區設定（Locale）

設定 SSH 連線後的語系環境變數（如 `en_US.utf8`、`zh_TW.utf8` 等），以確保終端機顯示的文字編碼與語言一致。
