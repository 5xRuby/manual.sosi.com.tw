## Telnet デバイス設定

Telnet は、リモートログインと端末エミュレーションのための長年にわたるネットワークプロトコルです。Telnet デバイスを設定する際は、Telnet 固有の端末パラメータを入力する必要があります。

### 基本設定

全デバイスタイプ共通の設定項目については、[デバイス一覧](/ja/admin/devices/)を参照してください：

- **デバイス識別名**
- **IP / ホスト名**
- **タイプ：** Telnet を選択
- **最大同時接続数**
- **ポート番号：** Telnet のデフォルトは **23**
- **備考**
- **接続時間制限**
- **管理者メールアドレス**

### Telnet 固有設定

#### カラースキーム（Color Scheme）

端末表示のカラーテーマを選択します：

| カラースキーム | 説明 |
|----------------|------|
| 白背景・黒文字 | 白色の背景に黒色の文字 |
| 黒背景・灰色文字 | 黒色の背景に灰色の文字 |
| 黒背景・緑文字 | 黒色の背景に緑色の文字（クラシック端末スタイル） |
| 黒背景・白文字 | 黒色の背景に白色の文字 |

#### フォント名（Font Name）

端末で使用するフォントを設定します（例：`monospace`、`Courier` などの等幅フォント）。

#### フォントサイズ（Font Size）

端末の文字表示サイズを **8** 〜 **40** pt の範囲で設定します。

#### スクロールバック（Scrollback）

端末バッファでスクロール可能な行数を設定します。値を大きくすると、より多くの履歴出力を保持できます。

#### 接続情報を表示（Show Connection Info）

有効にすると、接続元 IP や接続時間などの接続情報が端末画面の上部に表示されます。
