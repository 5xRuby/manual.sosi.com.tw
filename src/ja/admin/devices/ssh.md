## SSH デバイス設定

SSH（Secure Shell）は、安全でないネットワーク上でネットワークサービスを安全に操作するための暗号化ネットワークプロトコルです。SSH デバイスを設定する際は、SSH 固有の接続パラメータを入力する必要があります。

### 基本設定

全デバイスタイプ共通の設定項目については、[デバイス一覧](/ja/admin/devices/)を参照してください：

- **デバイス識別名**
- **IP / ホスト名**
- **タイプ：** SSH を選択
- **最大同時接続数**
- **ポート番号：** SSH のデフォルトは **22**
- **備考**
- **接続時間制限**
- **管理者メールアドレス**

### SSH 固有設定

#### 許可するドメイン（Host Key）

リモート SSH サーバーの Host Key（公開鍵）を入力し、サーバー身元を検証して中間者攻撃を防止します。

#### サーバー生存間隔（Server Alive Interval）

SSH 接続のキープアライブパケット送信間隔（秒単位）を設定します。ネットワークが不安定な環境で、アイドルタイムアウトを防ぎます。

#### コマンド（Command）

SSH 接続確立後に自動実行するコマンドやスクリプトを指定します。自動ディレクトリ移動や特定プログラムの起動に便利です。

#### ロケール（Locale）

SSH セッションのロケール環境変数（例：`en_US.utf8`、`ja_JP.utf8`）を設定し、ターミナルの文字エンコーディングと言語表示を統一します。
