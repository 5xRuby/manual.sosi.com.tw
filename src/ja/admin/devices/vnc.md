## VNC デバイス設定

VNC（Virtual Network Computing）は、RFB（Remote Frame Buffer）プロトコルを使用したリモートデスクトップ制御プロトコルです。VNC デバイスを設定する際は、VNC 固有の接続パラメータを入力する必要があります。

### 基本設定

全デバイスタイプ共通の設定項目については、[デバイス一覧](/ja/admin/devices/)を参照してください：

- **デバイス識別名**
- **IP / ホスト名**
- **タイプ：** VNC を選択
- **最大同時接続数**
- **ポート番号：** VNC のデフォルトは **5900**
- **備考**
- **接続時間制限**
- **管理者メールアドレス**

### VNC 固有設定

#### 自動リトライ（Auto Retry）

接続失敗時に自動的にリトライするかどうか、およびリトライ回数や間隔を設定します。

#### 色深度（Color Depth）

リモートデスクトップ接続の表示色品質を設定します：

| 色深度 | 説明 |
|--------|------|
| Low color (16-bit) | 低品質、帯域幅が限られた環境向け |
| True color (24-bit) | トゥルーカラー、より良い視覚効果 |
| True color (32-bit) | フルトゥルーカラー、アルファチャンネル対応 |
| 256 color | 最低色要件、ネットワーク環境が非常に悪い場合 |

色深度を下げることでネットワーク転送量を削減し、操作のスムーズさを向上できます。
